# راهنمای استفاده از BPB VPN برای ویندوز

رابط کاربری نسخه ویندوزی **دقیقاً همان نسخه اندروید است** — همان صفحه‌ها، ترتیب منوها، رنگ‌بندی، فونت و رفتار دکمه‌ها — فقط در یک پنجره‌ی دسکتاپ با ابعاد ثابت (۴۲۰×۷۶۰) که قابل تغییر اندازه نیست، تا چیدمان موبایل حفظ شود.

## پنجره‌ی اصلی (صفحه‌ی Home)

از بالا به پایین، مثل نسخه اندروید:

1. **نوار بالا:** آیکون و نام برنامه، منوی حالت اتصال (VPN / Proxy)، دکمه‌های Logs و Config و Settings.
2. **کارت وضعیت (Status Card):** دکمه‌ی گرد بزرگ روشن/خاموش با حلقه‌ی انیمیشنی؛ مدت‌زمان اتصال، پینگ (دکمه‌ی تست)، آی‌پی خروجی تونل و آی‌پی LAN.
3. **کارت‌های ترافیک:** سرعت لحظه‌ای بالا/پایین و مجموع ترافیک از شروع اتصال (نمونه‌برداری هر ثانیه از شمارنده‌های Xray، همان منطق نسخه اندروید).
4. **کارت انتخاب اتصال (Connection Card):** انتخاب نوع اتصال و حالت آن (بخش بعدی) و Exit Node / منطقه‌ی خروج.

## انواع اتصال و حالت‌های آن‌ها

| نوع | حالت‌ها | توضیح |
| --- | --- | --- |
| **Worker** | Normal / Fragment / Browser Dialer | اتصال VLESS از طریق Worker شما در Cloudflare؛ با انتخاب «تمیزترین» IP و پورت با کمترین پینگ |
| **WARP** | Normal / Obfuscated | اتصال WireGuard به Cloudflare WARP؛ با رزرو بایت‌ها و اسکن endpoint |
| **MASQUE** | HTTP/2 یا HTTP/3 | اتصال MASQUE به WARP با امکان fragment و نویز UDP |
| **Psiphon** | — | مستقیماً به شبکه‌ی Psiphon وصل می‌شود؛ بدون نیاز به Cloudflare |
| **Tor** | direct / snowflake / snowflake-amp / obfs4 / meek / custom | خروج Tor؛ پل‌ها را می‌توان از Tor Project گرفت یا دستی وارد کرد |
| **SSH** | — | تونل SSH با احراز هویت رمز/کلید و pin کردن host key |
| **Serverless** | DNS / Packet / Domain Fronting | اتصال بدون سرور فقط با fragment و نویز UDP؛ Domain Fronting به CA اختصاصی نیاز دارد |

هر نوع می‌تواند **Chain Proxy** داشته باشد (خروج از طریق یک کانفیگ دیگر مثل لینک v2ray یا WireGuard که در Settings → Chain proxies اضافه می‌شود) و برای Psiphon/Tor می‌توان **منطقه‌ی خروج** انتخاب کرد.

## تنظیمات (Settings) — به ترتیب نسخه اندروید

- **Global:** Chain proxies، DNS، IPv6، LAN Sharing (با نام کاربری/رمز)، Append HTTP Proxy (ست‌کردن پروکسی سیستم ویندوز در حین اتصال)، MTU، Per-app.
- **VLESS:** deployment فعال، پورت‌ها، TLS fingerprint، Custom CDN، ECH، Fragment، Upstream proxy، Proxy IPs، TCP Fast Open، سایتی که سقوط می‌کند (fallback)، Clean IPs + اسکنر REAL.
- **MASQUE / WARP:** SNI، fingerprint، fragment/noise، renew حساب، endpoints + اسکنر.
- **Tor:** گرفتن پل از Tor Project، پل‌های دستی.
- **SSH:** میزبان، پورت، کاربر، رمز/کلید، فاصله‌های keep-alive.
- **Serverless:** مدیریت DNS (UDP/TCP/DoH/DoQ با تست واقعی هر سرور)، Fake SNI، fragment و نویز، نصب گواهی MITM برای Domain Fronting.
- **Routing:** استراتژی دامنه، قوانین bypass (ایران/چین/روسیه)، sanction bypass (OpenAI، Docker، Adobe و…)، مسدودسازی (تبلیغات/پورن/بدافزار/فیشینگ/کریپتو-ماینر/QUIC) + دامنه‌ها و IPهای سفارشی، و به‌روزرسانی فایل‌های geo.
- **Import/Export:** خروجی/ورودی فایل تنظیمات (بدون بخش‌های خصوصی).
- **Appearance:** حالت روشن/تاریک و ۸ رنگ تم.
- **About:** نسخه‌ها (برنامه، Xray، Psiphon، Tor)، بررسی به‌روزرسانی از GitHub، اجرای مجدد نصب اولیه، صفحه‌ی مجوز و حمایت مالی.

## Per-app proxy در ویندوز

مثل اندروید یک فهرست از برنامه‌ها می‌سازید (برنامه‌های نصب‌شده‌ی ویندوز از Program Files و AppData) و حالت را انتخاب می‌کنید:

- **Include:** فقط ترافیک برنامه‌های انتخاب‌شده از تونل می‌گذرد.
- **Exclude:** همه‌چیز از تونل می‌گذرد به‌جز برنامه‌های انتخاب‌شده.

در ویندوز این کار با قوانین مسیریابی Xray روی نام پروسه انجام می‌شود؛ آیکن اختصاصی هر برنامه در این نسخه نمایش داده نمی‌شود و آیکن پیش‌فرض جای آن می‌نشیند.

## اسکنر REAL (یافتن IP و endpoint)

از Settings → Clean IPs / WARP / MASQUE باز می‌شود؛ روی ویندوز مانند اندروید داخل هسته اجرا می‌شود و IPهای پاسخ‌گو را می‌یابد (VLESS، WARP، MASQUE h2/h3). در حین اسکن نمی‌توان VPN فعال داشت (مثل اندروید).

## اگر WARP یا MASQUE در نصب اولیه ثبت نشد

ثبت‌نام WARP و MASQUE با سرور `api.cloudflareclient.com` گفت‌وگو می‌کند که در برخی شبکه‌ها (مثل ایران) مستقیم در دسترس نیست — در این حالت مراحل نصب اولیه برای Worker/Pages سبز می‌مانند اما WARP و MASQUE قرمز می‌شوند. سه راه بازیابی وجود دارد و هر سه از داخل خود برنامه‌اند:

1. **اتصال با یک حالت دیگر و سپس Register:** Psiphon (و Tor و Serverless) به WARP نیاز ندارند و مستقیم وصل می‌شوند. با Psiphon وصل شوید، سپس در Settings → Warp یا Masque دکمه‌ی Register را بزنید — درخواست این‌بار از داخل تونل می‌رود و ثبت می‌شود. بعد از آن می‌توانید حالت را روی WARP یا MASQUE بگذارید و وصل شوید.
2. **Retry with Tor:** در Settings → Warp یا Masque بعد از خطای شبکه، گفت‌وگوی بازیابی دکمه‌ی «Retry with Tor» دارد؛ برنامه Tor را با پل‌های داخل خودش (obfs4، snowflake، webtunnel و meek-azure) بالا می‌برد و ثبت‌نام را از داخل Tor انجام می‌دهد. درصد اتصال Tor نمایش داده می‌شود.
3. **تکرار کامل نصب از ابتدا:** Settings → About → **Run setup again** — بعد از تأیید، حساب‌های Cloudflare و Worker/Pages آن‌ها حذف می‌شوند (در صورت در دسترس بودن Cloudflare، از خود Cloudflare هم پاک می‌شوند)، ثبت‌نام‌های WARP و MASQUE پاک می‌شوند و ویزارد از گام ۱ باز می‌شود. با تیک «Also reset all other settings» بقیه‌ی تنظیمات هم به پیش‌فرض برمی‌گردند. (فقط برای Worker/Pages و بدون پاک‌سازی، مسیر کوتاه‌تر Settings → Cloudflare accounts → Add account هم هست.)

نکته: اگر «Retry with Tor» نمایش داده نشد، یعنی این بیلد پل ندارد (فایل bridges.json در زمان ساخت گرفته نشده) — از راه ۱ استفاده کنید.

## توقف نصب در مراحل اولیه

در گام «Install» دکمه‌ی **Stop** همیشه در دسترس است — چه درخواست‌ها در جریان باشند چه Tor در حال اتصال. با توقف، ردیف‌ها «Stopped» می‌شوند و انتخاب‌ها (Retry / Retry with Tor / Skip for now) برمی‌گردند؛ درخواست‌هایی که دیر به سراغشان جواب برسد استفاده نمی‌شوند و حسابی هم اضافه نمی‌شود. گفت‌وگوی بازیابی WARP/MASQUE در Settings هم دکمه‌ی Stop دارد که Tor را متوقف می‌کند.

## لاگ‌ها و پیکربندی

- **Config:** پیکربندی JSON فعلی Xray را نمایش می‌دهد (با هایلایت) و امکان ذخیره دارد.
- **Logs:** لاگ Xray و در صورت استفاده، Tor و Psiphon را زنده نشان می‌دهد؛ لاگ‌ها با هر اتصال پاک می‌شوند و در `%LOCALAPPDATA%\BPBVPN\core` ذخیره می‌مانند.

## چند نکته‌ی ویندوزی

- **بستن پنجره** اتصال را قطع نمی‌کند؛ سرویس در پس‌زمینه می‌ماند و اجرای دوباره‌ی برنامه به همان سرویس وصل می‌شود (مثل سرویس پیش‌زمینه در اندروید). برای قطع کامل، Disconnect بزنید یا از Task Manager سرویس `bpbcore.exe` را ببندید.
- **Append HTTP Proxy** در ویندوز یعنی تنظیم پروکسی سیستم (WinINET) به `127.0.0.1:10808` در حین اتصال؛ برنامه‌هایی که از پروکسی سیستم پیروی می‌کنند بدون تنظیم، از تونل می‌گذرند.
- **اسکن QR:** دوربین وجود ندارد؛ در Import، گزینه‌ی QR یک تصویر از کد را می‌گیرد و داخل هسته دیکد می‌کند.
