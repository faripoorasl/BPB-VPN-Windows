# نصب و راه‌اندازی BPB VPN برای ویندوز

این سند راهنمای نصب نسخه ویندوزی برنامه BPB VPN است. برای آشنایی با امکانات برنامه، [راهنمای استفاده](USAGE-FA.md) و برای فهرست کامل قابلیت‌ها و نتیجه تست‌ها، [گزارش قابلیت‌ها و تست](FEATURES-TEST-REPORT-FA.md) را ببینید.

## ۱. نیازمندی‌ها

| مورد | جزئیات |
| --- | --- |
| سیستم‌عامل | Windows 10 یا Windows 11 (نسخه ۶۴ بیتی) |
| معماری | x64 / AMD64 |
| دسترسی | حساب کاربری با اجازه‌ی نصب برنامه؛ برای حالت VPN، حق Administrator در لحظه‌ی اتصال |
| فضای دیسک | حدود ۲۰۰ مگابایت |
| اینترنت | برای راه‌اندازی اولیه (استقرار Worker در Cloudflare) و اتصال |

## ۲. روش اول: نصب‌کننده (پیشنهادی)

1. از صفحه‌ی [Releases مخزن](https://github.com/faripoorasl/BPB-VPN-Windows/releases) فایل `BPB-VPN-Setup-x.y.z-windows-x64.exe` را دانلود کنید.
2. checksum فایل را (در صورت تمایل) با `SHA256SUMS.txt` همان Release مقایسه کنید:
   ```powershell
   Get-FileHash .\BPB-VPN-Setup-1.3.2-windows-x64.exe -Algorithm SHA256
   ```
3. روی فایل دوبار کلیک کنید؛ در پنجره‌ی User Account Control (UAC) تأیید کنید تا نصب‌کننده اجرا شود.
4. نصب به‌صورت پیش‌فرض در `C:\Program Files\BPB VPN` انجام می‌شود و یک میان‌بر در منوی استارت (و در صورت انتخاب، روی دسکتاپ) ساخته می‌شود.
5. برنامه را اجرا کنید؛ ویزارد راه‌اندازی (Setup Wizard) همان مسیر نسخه اندروید را باز می‌کند.

## ۳. روش دوم: نسخه Portable

1. فایل `bpb-x.y.z-windows-x64.zip` را از Releases دانلود و در پوشه‌ی دلخواه (مثلاً `D:\BPB-VPN`) باز کنید.
2. برنامه از داخل پوشه بدون نصب اجرا می‌شود: `BPB-VPN.exe`.
3. تمام فایل‌های جانبی (`bpbcore.exe`، `wintun.dll`، `psiphon.exe`، پوشه‌ی `tor` و `resources`) باید کنار برنامه باقی بمانند؛ پوشه را دسته‌جمعی جابه‌جا کنید.

## ۴. اجازه‌های موردنیاز ویندوز

- **حالت VPN** (TUN): در اولین اتصال، یک پنجره‌ی UAC نمایش داده می‌شود تا سرویس هسته (`bpbcore.exe`) با دسترسی Administrator اجرا شود؛ این دسترسی برای ساخت آداپتور مجازی (Wintun) و مسیردهی ترافیک سیستم لازم است. اگر UAC را رد کنید، پیام برنامه پیشنهاد می‌کند از **حالت Proxy** استفاده کنید که به هیچ دسترسی ویژه‌ای نیاز ندارد.
- **حالت Proxy**: بدون UAC؛ فقط یک پروکسی محلی SOCKS/HTTP روی `127.0.0.1:10808` اجرا می‌شود که هر برنامه‌ای می‌تواند از آن استفاده کند.
- درایور **Wintun** به‌صورت یک فایل DLL کنار هسته قرار دارد و نصب سیستم‌ی جداگانه لازم ندارد.

## ۵. راه‌اندازی اولیه (مثل نسخه اندروید)

1. در ویزارد اولیه، **Cloudflare API Token** خود را وارد کنید (لینک ساخت توکن داخل برنامه باز می‌شود).
2. برنامه به‌صورت خودکار دو استقرار **Workers** و **Pages** را در حساب Cloudflare شما می‌سازد.
   - اگر شبکه مانع اتصال شد، گزینه‌ی **«Retry with Tor»** با پل‌های داخلی همان کار را از طریق Tor انجام می‌دهد.
3. پس از اتمام، صفحه‌ی اصلی باز می‌شود و انواع اتصال در دسترس‌اند: Worker، WARP، MASQUE، Psiphon، Tor، SSH و Serverless.
4. دکمه‌ی بزرگ روشن/خاموش را بزنید تا وصل شوید؛ وضعیت اتصال، سرعت و پینگ همان لحظه نمایش داده می‌شود.

## ۶. رفع اشکال‌های رایج

| مشکل | راه‌حل |
| --- | --- |
| پنجره UAC ظاهر نمی‌شود یا رد شده | حالت اتصال را روی Proxy بگذارید، یا اتصال را دوباره و در پنجره UAC تأیید کنید |
| «درایور Wintun پیدا نشد» | مطمئن شوید `wintun.dll` کنار `bpbcore.exe` باقی مانده است (در نسخه Portable) |
| پورت‌های محلی اشغال است («Another process is using the local proxy ports») | برنامه دیگری (مثل یک کلاینت VPN دیگر) از پورت‌های 10808–10832 استفاده می‌کند؛ آن را ببندید |
| اتصال Worker برقرار نمی‌شود | از Settings → Cloudflare accounts وضعیت استقرارها را ببینید؛ نسخه‌ی اسکریپت را به‌روز کنید |
| آنتی‌ویروس فایل‌ها را علامت می‌زند | همه‌ی اجزا از سورس رسمی/Xray-core/Tor Project/Wintun رسمی ساخته شده‌اند؛ در صورت نیاز پوشه را exception کنید |

## ۷. حذف برنامه

- **نسخه نصبی:** از Settings → Apps یا کنترل پنل، «BPB VPN» را Uninstall کنید (داده‌های محلی در `%LOCALAPPDATA%\BPBVPN` نیز پاک می‌شوند).
- **نسخه Portable:** پوشه را حذف کنید و در صورت تمایل `%LOCALAPPDATA%\BPBVPN` را نیز پاک کنید. اگر هنگام حذف اتصال فعال است، ابتدا Disconnect کنید.
